# Video de demostración

Poné acá el video que muestra el flujo completo: cargar plantilla → cargar Excel →
diseñar → generar → certificado final.

## Nombre esperado por el README

- `demo-completa.mp4`

## Recomendaciones

- Duración: **1 a 3 minutos**. Mostrá el "antes y después": una planilla y, al final,
  la carpeta llena de certificados generados.
- **Datos ficticios** en toda la grabación.
- GitHub reproduce videos `.mp4` directamente en la página, pero **el archivo debe pesar
  menos de 100 MB** (límite de GitHub por archivo). Si pesa más:
  - Comprimilo (por ejemplo con HandBrake), o
  - Subilo a YouTube como "**no listado**" y poné el enlace en el README. Un video no
    listado no aparece en búsquedas, pero cualquiera con el link lo puede ver — ideal para
    mandárselo a instituciones.
- Para grabar la pantalla en Windows: **Xbox Game Bar** (tecla `Win + G`) o **OBS Studio**.
- Este archivo `LEEME.md` podés borrarlo una vez que agregues el video.
