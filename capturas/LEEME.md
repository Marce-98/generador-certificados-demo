# Capturas de pantalla

Poné acá las imágenes que muestran el producto funcionando. El README espera estos nombres
exactos (podés cambiarlos, pero entonces actualizá los enlaces del README):

- `01-editor.png` — el editor visual con la plantilla cargada y un bloque de texto
- `02-formato.png` — el panel de tramos con una variable en negrita (N/K/S)
- `03-generacion.png` — la pantalla del paso 4 generando los certificados
- `04-resultado.png` — un certificado final ya generado (con datos ficticios)

## Recomendaciones

- **Usá datos ficticios** (nombres inventados, DNI 12345678). Nunca subas capturas con
  datos reales de personas.
- Formato **PNG**. Ancho ideal: 1200–1600 px.
- Recortá la ventana del navegador para que se vea prolijo (sin barras ni pestañas con
  información personal).
- Este archivo `LEEME.md` podés borrarlo una vez que agregues las imágenes.
